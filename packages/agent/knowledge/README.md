# The Takewon guide

Mirrored into Mastra Knowledge (scope `docs:takewon`) every time the agent server boots.
Each markdown file here is one page, at its path without `.md`. The page name is the
frontmatter `name`, else the first `# heading`, else the file name; a frontmatter
`description` becomes the page description.

Edit a file and restart: the page updates. Delete a file: its page is removed. `README.md`
files (like this one) are skipped. Every chat reads these pages; no chat can change them.
