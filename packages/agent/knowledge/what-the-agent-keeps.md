# What the agent keeps

The agent keeps pages of notes, and each page belongs to one place:

- **The Takewon guide**: these pages. Every team reads them; nobody changes them from a chat.
- **Your team**: how your team likes things done, written when someone on the team asks the
  agent to remember it. Everyone on the team sees these pages, in their own chats. Another
  team never does.
- **A client**: what one client wants and avoids, with a **Client brief** page the agent
  keeps in mind. The agent reads a client's pages only while something for that client is
  open on your screen: its automation, a run of it, a file made for it, its project or the
  client's own page. Work for one client never picks up another client's notes.
- **You**: notes only you see, kept apart for each team you are on.

The agent asks before it writes or changes a page, and before it keeps one in mind on
every turn.
